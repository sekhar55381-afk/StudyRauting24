# StudyRauting24

A colorful, professional study + coding tracker for daily routine management.

## Features
- Student login and admin login
- Modern dashboard with stats cards
- Daily timetable and attendance tracking
- Subject progress view
- Admin panel for student monitoring
- Responsive UI for desktop and mobile

## Run locally
1. Open `index.html` in a browser, or
2. Start a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Demo login
- Student: `student@study.com` / `student123`
- Admin: `admin@study.com` / `admin123`

## Project structure
- `index.html` – app layout
- `styles.css` – design and responsive styling
- `script.js` – login logic, dashboard rendering, and attendance simulation
